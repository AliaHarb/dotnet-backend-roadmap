# 📌 Week 01 — Task Tracker Project

<text></text>
## 🎯 Objective

Build a Task Tracker application using C# to practice the fundamental programming concepts and create an application that allows users to manage and track their tasks efficiently.

## 📋 Requirements

The application should allow users to:

1. **Add Tasks**
   - Add new tasks with:
     - Title
     - Description
     - Due Date
     - Priority

2. **Update Tasks**
   - Change the task status:
     - Pending
     - In Progress
     - Completed

3. **View Tasks**
   - Display tasks in different categories:
     - Active
     - Overdue
     - Completed

4. **Delete Tasks**
   - Delete tasks that are no longer needed.

5. **Exit Application**
   - Allow users to exit the application safely.
   - Show a confirmation prompt to prevent accidental closures.

## 💡 Expected Outcome

A Task Tracker application that allows users to create, manage, update, view, and delete tasks efficiently.
