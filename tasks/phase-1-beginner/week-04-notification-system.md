# 🔔 Week 04 — Notification System

## 🎯 Objective

Build a Notification System using C# to practice Events and Delegates by implementing a system where users can subscribe to different notification channels and receive updates.

## 📋 Requirements

The system should support the following features:

1. **Subscribe to Channels**
   - Allow users to subscribe to:
     - News
     - Sports
     - Promotions

2. **Unsubscribe from Channels**
   - Allow users to unsubscribe from any channel.

3. **Publish Notifications**
   - Allow notifications to be published to different channels.

4. **Notify Subscribers**
   - Notify all subscribers of a channel when a new notification is published.
   - Use Events to notify subscribers.
   - Use Delegates to define event handlers.

5. **Message History**
   - Keep a history of sent notifications.
   - Store timestamps for notifications.

6. **Do Not Disturb**
   - Support a Do Not Disturb feature.

## 💡 Expected Outcome

A Notification System that uses Events and Delegates to manage subscriptions and notify users when new messages are published.
