# 📚 Week 02 — Library Management System

## 🎯 Objective

Build a Library Management System using C# to practice managing books and library members, while applying the fundamental programming concepts.

The system should support basic library operations such as adding, removing, displaying, borrowing, and returning books.

## 📋 Requirements

The application should support the following operations:

1. **Library Card**
   - Allow a user to have a library card.

2. **Manage Books**
   - Allow the librarian to:
     - Add new books.
     - Remove existing books.
     - Display available books.

3. **Borrow and Return Books**
   - Support borrowing and returning books.
   - Handle book due dates and library members.

## 💡 Expected Outcome

A Library Management System that supports basic book and member management operations.
