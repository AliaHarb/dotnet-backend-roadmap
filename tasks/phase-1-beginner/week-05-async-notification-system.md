# ⚡ Week 05 — Async Notification System

## 🎯 Objective

Extend the Notification System from Week 04 by introducing asynchronous notification delivery using C# Async/Await.

## 📋 Requirements

The system should support the following features:

1. **Asynchronous Notification Delivery**
   - Use `async` and `await` to deliver notifications.
   - Simulate delays during notification delivery.

2. **Non-Blocking Execution**
   - Allow multiple notifications to be processed without blocking the main application flow.

3. **Notification History**
   - Keep a history of sent notifications.
   - Store timestamps for notifications.

4. **Console Notification**
   - Use `Console.Beep` as part of the notification behavior.

5. **Unsubscribe All**
   - Allow a user to unsubscribe from all channels.

6. **Admin View**
   - Allow the admin to view active users.

## 💡 Expected Outcome

An extended Notification System that delivers notifications asynchronously and supports multiple notification operations without blocking the main flow.
