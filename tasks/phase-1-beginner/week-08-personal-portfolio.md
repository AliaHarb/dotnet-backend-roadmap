# 🌐 Week 08 — Personal Portfolio Website

## 🎯 Objective

Build a Personal Portfolio Website to showcase your bio, skills, and projects using HTML, CSS, Bootstrap, and JavaScript.

## 📋 Requirements

The website should include the following sections:

1. **About**
   - Introduce yourself and provide a short bio.

2. **Skills**
   - Display your technical skills.

3. **Portfolio**
   - Showcase your projects.

4. **Contact**
   - Provide a way for visitors to contact you.

## 🛠️ Technical Requirements

- **HTML:** Use HTML to structure the website.
- **CSS / Bootstrap:** Style the website and make it responsive.
- **JavaScript:** Add interactive features, such as:
  - Form validation.
  - Image slider.

## 💡 Expected Outcome

A clean, responsive, and mobile-friendly Personal Portfolio Website that showcases your information, skills, and projects.
