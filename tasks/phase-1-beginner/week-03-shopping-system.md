# 🛒 Week 03 — Shopping System

## 🎯 Objective

Build a Shopping System using C# to practice managing a shopping cart and handling user actions.

## 📋 Requirements

The application should allow users to:

1. **Add Items**
   - Add items to the shopping cart.

2. **View Cart**
   - Display all items currently in the cart.

3. **Remove Items**
   - Remove items from the shopping cart.

4. **Checkout**
   - Complete the checkout process.
   - Display an order summary.

5. **Undo Last Action**
   - Allow users to undo their last action.

6. **Calculate Total**
   - Calculate and display the total price of the cart.

7. **Exit Application**
   - Allow users to exit the application.

## 💡 Expected Outcome

A Shopping System that allows users to manage their cart, undo their last action, and complete checkout while displaying the total price.
