# 🎓 Week 01 — Student Management MVC

## 🎯 Objective

Build a basic Student Management application using ASP.NET Core MVC to practice working with Models and Controllers.

## 📋 Requirements

### 1. Create the Student Model

Create a `Student` model with the following properties:

- Id
- Names
- Address
- Img

### 2. Create a Student List

- Use a static `StudentList` to store student data.

### 3. Create StudentController

Implement the following actions:

- **Index:** Display all students.
- **Details(id):** Display the details of a specific student using their ID.

## 💡 Expected Outcome

A basic ASP.NET Core MVC Student Management application that displays all students and allows viewing an individual student's details.
