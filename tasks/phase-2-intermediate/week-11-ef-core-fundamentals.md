# 🏢 Week 11 — EF Core Fundamentals

## 🎯 Objective

Build an Employee & Project Management System using C#, Entity Framework Core, and SQL Server to practice database operations and Code First development.

## 📋 Requirements

Create the following entities:

1. **Department**
   - Id
   - Name

2. **Employee**
   - Id
   - Name
   - Email
   - Salary

3. **Project**
   - Id
   - Name
   - Description

The application should support the following operations:

- Add records.
- Edit existing records.
- Delete records.
- Display all records.

## 🛠️ Technical Requirements

- Use Entity Framework Core.
- Use SQL Server as the database.
- Apply the Code First approach.
- Create and apply the initial migration.
- Implement CRUD operations for the entities.

## 💡 Expected Outcome

An Employee & Project Management System connected to SQL Server using EF Core, with the required entities and CRUD operations.
