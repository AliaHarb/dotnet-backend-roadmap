# 🧩 Week 13 — Design Patterns Mini Task

## 🎯 Objective

Choose and implement one Design Pattern from the studied resources in a simple C# scenario.

## 📋 Requirements

1. **Choose a Design Pattern**
   - Select one pattern from the studied resources.

2. **Implement the Pattern**
   - Create a simple C# scenario that demonstrates the selected pattern.

3. **Explain Your Choice**
   - Describe the problem the pattern addresses.
   - Explain why you chose this pattern for the scenario.

4. **Demonstrate the Implementation**
   - Show how the pattern works in your example.

## 💡 Examples

You can choose one of the following patterns:

- Singleton
- Adapter
- Strategy
- Factory

## 💡 Expected Outcome

A small C# implementation of one Design Pattern, accompanied by an explanation of the problem it solves and why it was selected.
