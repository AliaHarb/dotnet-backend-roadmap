# 📗 .NET Backend Roadmap

> 🌱 **Start with curiosity, not perfection.**
>
> This roadmap is a journey focused on understanding, practicing, and improving step by step.

A structured learning path for aspiring .NET Backend Developers, covering programming fundamentals, databases, ASP.NET Core, software architecture, and production-ready applications.

---

## 🗺️ Roadmap Overview

| Level | Focus |
|---|---|
| 🌱 [Entry Level](#-entry-level--getting-started) | Introduction, Web Basics, Git & GitHub |
| 🟢 [Phase 1 — Beginner](#-phase-1--beginner) | C# Fundamentals & Database Foundations |
| 🟡 [Phase 2 — Intermediate 1](#-phase-2--intermediate-1) | LINQ & Entity Framework Core |
| 🔵 [Phase 3 — Intermediate 2](#-phase-3--intermediate-2-aspnet-core) | ASP.NET Core MVC, Web API & Security |
| 🟣 [Phase 4 — Advanced](#-phase-4--advanced-topics) | Architecture, Performance, Testing & Advanced Backend Topics |
| ☁️ [Deployment & Production](#-deployment--production) | Azure & Docker |
| 🤖 [AI for Developers](#-ai-for-developers) | Prompt Engineering & MCP |
